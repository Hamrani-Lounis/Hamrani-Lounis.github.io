// 01 — projets

Projets

Un même domaine métier (la réservation de salles), traité dans trois technologies : une interface web typée, un programme système en C et une base de données relationnelle. Tout le code est public.

01 TypeScript

Application web de réservation de salles

Application monopage développée sans framework externe.

  • Algorithme métier de détection et de résolution des conflits de créneaux horaires
  • TypeScript en mode strict, modèle de données entièrement décrit par interfaces
  • Persistance locale des données côté navigateur
TypeScript (strict) HTML5 CSS3 natif
Hamrani-Lounis/booking-typescript
02 C

Gestionnaire de réservations en console

Application modulaire avec compilation automatisée via Makefile.

  • Gestion rigoureuse de la mémoire dynamique (malloc / free)
  • Persistance des structures sur disque via fichiers binaires
  • Découpage en modules et compilation séparée
C99 Makefile Bash
Hamrani-Lounis/booking-c
03 SQL

Schéma relationnel et requêtes analytiques

Conception intégrale de la base de données de réservation.

  • Clés primaires / étrangères, contraintes d'intégrité et index
  • 10 requêtes analytiques : taux d'occupation, détection de disponibilité
  • Jointures multi-tables et agrégations
MySQL MCD / MLD Modélisation relationnelle
Hamrani-Lounis/booking-mysql
